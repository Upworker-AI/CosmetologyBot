# CosmetologyBot

# Telegram-бот для записи в косметологическую студию

Бот помогает клиентам посмотреть услуги и цены, узнать об акциях и оставить заявку на запись.

## Возможности

- Каталог услуг по категориям
- Цены, длительность и описание услуг
- Заявка на запись через пошаговую форму
- Отдельный сценарий для курсов
- Уведомление владельцу о новой заявке
- Подтверждение или отмена заявки владельцем
- Команда `/my_bookings` для клиента

## Запуск

1. Создайте виртуальное окружение:
   ```bash
   python -m venv venv
   venv\Scripts\activate
   ```

2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```

3. Создайте `.env`:
   ```env
   BOT_TOKEN=ваш_токен
   DATABASE_PATH=bot.db
   OWNER_TELEGRAM_ID=ваш_telegram_id
   ```

4. Запустите бота:
   ```bash
   python main.py
   ```

5. При первом запуске добавьте услуги:
   ```bash
   python -m database.seed
   ```
